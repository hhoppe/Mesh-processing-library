# Demos

The scripts in this directory demonstrate the programs of the [Mesh Processing Library](../README.md).
Each `create_*` script processes inputs from `data/` and writes outputs to `results/`,
and each `view_*` script shows results interactively.
Every demo exists both as a `bash` script (`*.sh`) and as a Windows batch file (`*.bat`).

See [Demos](../make/README.md#demos) for how to run them, and the
[list of publications](../README.md#publications) for the demos associated with each paper.
